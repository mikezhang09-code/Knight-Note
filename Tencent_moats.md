

# Tencent Moat Analysis & Big Tech Comparison

## 1. Overview

Tencent’s competitive advantage (moat) is not a single product but a **multi-layered system** combining:

* Social networks
* Payments infrastructure
* Platform ecosystem
* Content & gaming
* Investment network
* Data & AI

This creates a **compound moat**, where each layer reinforces the others.

# 2. Tencent Moat Framework

## 2.1 Social Graph Network Effects

**Core assets:** WeChat, QQ

### Key characteristics:

* Strong network effects
* High switching costs
* Daily habit formation

### Key metrics:

* MAU / DAU
* DAU/MAU ratio
* Connections per user

### Conceptual model:

```
Users → Messages → Content → Services → More users
```

* Time spent per user

# 6. Key Strategic Insight

Tencent is unique because it combines:

1. **Social network (Meta-like)**
2. **Payments (Visa-like)**
3. **Platform ecosystem (Apple-like)**

This creates a **closed-loop economy inside one app**.

# 7. Final Takeaway

Tencent’s moat is best understood as a **compound system**:

```
Social Graph
     ↓
Payments
     ↓
Platform (Mini-programs)
     ↓
Services & Commerce
     ↓
Content & Gaming
     ↓
Investment Network
```

### Why this matters:

* Each layer increases switching costs
* Each layer feeds data into the system
* Each layer reinforces user dependency
